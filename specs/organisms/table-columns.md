# أعمدة الجدول — `<app-table-columns>`

> أن يرى المستخدم في الجدول ما يهمّه هو: يُخفي عمودًا لا يستعمله، ويقدّم عمودًا يقرؤه أوّلًا. والجدول يتغيّر فورًا تحت اللوحة.

## 1. متى تستخدمه

> **الحالة:** في صفحة الدورات (`/admin/products/courses`، قرار المنتج 2026-09-24 — «نفذه الآن في صفحة الدورات فقط»)، وفي بطاقات «نظرة عامة» (`/admin/dashboard`، 2026-09-24 — § خارج الجدول). بقية الجداول تتبنّاه بطلب.

← «خارج الجدول» في §4.

## 2. متى لا تستخدمه

**متى لا يُستعمل:** جدول بأعمدة قليلة (ثلاثة أو أربعة) — كلّها تُقرأ بنظرة، والزرّ أداة بلا حاجة. وجدول في بطاقة ضيّقة.

## 3. التشريح

```text
[⌕ البحث باسم الدورة    ] [⧩ فلترة النتائج]        [⤓ تصدير كملف إكسل] [▥ الأعمدة]
                                                   ┌──────────────────────────┐
                                                   │ 🔒 ☑ الدورة         ثابت │  ① الثابت
                                                   │ ⠿ ☑ المدرب              │
                                                   │ ⠿ ☑ الاشتراكات          │  ② المتحرّكة
                                                   │ ⠿ ☐ في أكاديميات بلس    │
                                                   ├──────────────────────────┤
                                                   │ ↻ استعادة الافتراضي       │  ③ الذيل
                                                   └──────────────────────────┘
```

* **الزرّ** — `dsButton variant="secondary"` بأيقونة `grid/row-horizontal` ونصّ «الأعمدة»، **آخر طرف الأفعال** في `<app-table-toolbar>` بعد التصدير.
* **① الثابت** — العمود الذي يُعرف به الصفّ («الدورة» بغلافها): قفل `security/lock` مكان المقبض، ومربّع مختار معطَّل، و«ثابت» بجانبه. لا يتحرّك ولا يُخفى: بدونه لا يُعرف أيّ صفّ لأيّ دورة.
* **② المتحرّكة** — لكلّ عمود مقبض السحب نفسه الذي في صفوف الجدول (`essential/grip-horizontal`، [`sortable.md`](../molecules/sortable.md)) ومربّع `<app-checkbox>` باسمه. الضغط على الاسم يبدّل المربّع.
* **③ الذيل** — «استعادة الافتراضي» (`tertiary` · `sm` · `arrow/refresh-arrow-01`): الترتيب الأصلي وكل الأعمدة ظاهرة. معطَّل ما دام لا شيء تغيّر.

**ليست أعمدة:** خانة التحديد ومقبض الصفّ في أوّله، وزرّا «تعديل» و⋯ في آخره — أدوات الصفّ لا بياناته.

## 4. الأنواع والمقاسات

### خارج الجدول — بطاقات «نظرة عامة»

اللوحة نفسها ترتّب **بطاقات** صفحة وتُخفيها، لا أعمدة جدول وحدها (طلب المنتج 2026-09-24: «زر أقدر أخفي أو أظهر البلوكات والترتيب» في «التقارير والإحصائيات»). السؤال واحد — ماذا أرى وبأيّ ترتيب — فلا لوحة ثانية له.

```html
<!-- في سطر الفترة، طرف النهاية -->
<app-table-columns label="تخصيص البطاقات" heading="بطاقات نظرة عامة"
                   [columns]="blockDefs" [state]="blocksState" (stateChange)="onBlocksChange($event)" />
```

* **الزرّ** «تخصيص البطاقات» في طرف نهاية سطر الفترة (`appDashboardPeriod`)، فيلتصق معه في الشريط الثابت. على الجوال يلتفّ تحت الحقل.
* **الأسماء** عناوين البطاقات حرفًا بحرف، وفي القناة المفتوحة: «المبيعات حسب طريقة الدفع» في الموقع و«الزيارات حسب المصدر» في أكاديميات بلس — المفتاح واحد (`sources`) والترتيب واحد للقناتين.
* **لا بطاقة ثابتة:** كلّها تُخفى وتتحرّك. والفترة فوقها ليست بطاقة.
* **الشبكة بعمودين** ترسم الظاهرة بترتيب المستخدم (`@for` بترتيب DOM لا `order` في CSS — قارئ الشاشة وTab بترتيب العين). «الأرقام السريعة» و«المبيعات» بعرض الصفحة دائمًا، والبطاقة بنصف العرض التي بقيت وحدها في صفّها — قبل بطاقة عريضة أو آخر الشبكة — تتمدّد بعرض الصفحة (`blockSlots`)، فلا خانة فارغة بعد إخفاء أو نقل.
* **كل البطاقات مخفية:** حالة فارغة «كل البطاقات مخفية» برسمة `no-content.svg` وزرّ «إظهار كل البطاقات» (الترتيب الأصلي وكلّها ظاهرة).
* **ليس «إضافة إحصائيات»:** ذلك الزرّ داخل بطاقة «الأرقام السريعة» يختار **الأرقام** فيها ويحفظها الخادم (`academy/statistics`)؛ هذا يرتّب **البطاقات** ويُخفيها.
* **الحفظ** بمفتاح `admin-dashboard-overview` في هذا المتصفح حتى [`REQ-079`](../../BACKEND-REQUIREMENTS.md).

## 5. الحالات

المذكور في الأصل متفرّق: «استعادة الافتراضي» معطَّل ما دام لا شيء تغيّر، والعمود الثابت مربّع مختار معطَّل (§3)؛ والزرّ يبقى فوق «لا نتائج» (§8)؛ و«كل البطاقات مخفية» حالة فارغة (§4).

وجدول الحالات كما يرسمها الكود (وُثّق 2026-09-26 من الكود — [`table-columns.component.ts`](../../../src/app/shared/ui/table/table-columns.component.ts)):

| الجزء | الحالة | الشكل |
|---|---|---|
| الزرّ «الأعمدة» | كلها | حالات `dsButton variant="secondary"` ([`button.md`](../atoms/button.md))؛ ومفتوحًا `aria-expanded="true"` بلا شكل خاصّ |
| المقبض | تمرير | `surface-sunken` و`text-primary` (ساكنًا `text-muted` بلا خلفية) |
| المقبض | تركيز | `--ds-focus-ring` |
| المقبض | ضغط | مؤشّر `grabbing` (ساكنًا `grab`) |
| المقبض | نقل بالسهمين / سحب | حالات [`sortable.md`](../molecules/sortable.md): فراغ رمادي، ونسخة مرفوعة، ووميض بعد الإفلات |
| صفّ العمود | تمرير | لا شكل خاصّ بالصفّ — المربّع وحده يتفاعل ([`checkbox-radio-switch.md`](../atoms/checkbox-radio-switch.md)) |
| العمود الثابت | معطَّل | قفل `security/lock` مكان المقبض بلا تفاعل، ومربّع مختار معطَّل |
| «استعادة الافتراضي» | معطَّل | `[disabled]` ما دامت الحالة الافتراضية (`isDefaultColumnsState`) — حالة `tertiary` المعطّلة |
| اللوحة | مفتوحة | تُرسم في `body` عبر `FloatingPanel`؛ مغلقة لا وجود لها في DOM |
| تحميل · خطأ | — | لا ينطبق: القائمة من تعريف الصفحة لا من الخادم |

## 7. الواجهة البرمجية

| المُدخل | النوع | الافتراضي | |
|---|---|---|---|
| `columns` | `readonly TableColumn[]` | `[]` | كل الأعمدة بترتيبها الافتراضي: `key` (ثابت — يُحفظ) · `label` (اسم الرأس حرفًا بحرف) · `locked?` |
| `state` | `TableColumnsState` | `{ order: [], hidden: [] }` | `{ order, hidden }` للمتحرّكة وحدها |
| `label` | `string` | `'الأعمدة'` | نصّ الزرّ |
| `heading` | `string` | `'أعمدة الجدول'` | اسم اللوحة وقائمتها لقارئ الشاشة |

| المُخرج | يحمل | |
|---|---|---|
| `stateChange` | `TableColumnsState` | مع كل تبديل ونقل واستعادة — يسري فورًا بلا «تطبيق» |

**دوالّ `table-columns.ts`** (وُثّق 2026-09-26 من الكود) — خالصة، تستعملها الصفحة واللوحة معًا:

| الدالّة | ما تفعله |
|---|---|
| `defaultColumnsState(columns)` | الترتيب كما عُرِّف وكل الأعمدة ظاهرة |
| `normalizeColumnsState(columns, state)` | يصحّح حالةً محفوظة على تعريف اليوم (§8 «الحفظ») |
| `visibleColumnKeys(state)` | الأعمدة المتحرّكة الظاهرة بترتيبها — ما ترسمه الصفحة بعد الثابتة |
| `isDefaultColumnsState(columns, state)` | هل الحالة هي الافتراضية — يعطّل «استعادة الافتراضي» |
| `readColumnsState(key, columns)` | الحالة المحفوظة في المتصفح أو `null` |
| `writeColumnsState(key, columns, state)` | يحفظها، أو يمسح المفتاح إن كانت الافتراضية |

وفي المكوّن `close(restoreFocus = true)` عامّة: تُغلق اللوحة، وتعيد التركيز إلى الزرّ إلا بـ`false`.

## 8. السلوك ولوحة المفاتيح

* **مُتحكَّم به:** الصفحة تملك الحالة وترسم منها، واللوحة تعرضها وتُطلق الجديدة. لا حالة مخفية داخلها.
* **فوري بلا «تطبيق»** — كلوحة الفلترة: الجدول تحتها يقول أثر كل نقرة.
* **الترتيب** بالسحب أو بلوحة المفاتيح: Tab إلى المقبض، ↑↓ ينقل ويُعلن «المدرب: الموضع 2 من 5»، والتوقّف ثانية أو Enter يحفظ، وEscape يلغي النقل ([`sortable.md`](../molecules/sortable.md)).
* **الإغلاق:** Escape (الثانية — الأولى تلغي نقلًا جاريًا)، والنقر خارجها، وخروج التركيز منها بـ Tab. التركيز يعود إلى الزرّ إلا حين يغلقها نقرٌ في مكان آخر. والنقرة التي تتبع إفلات السحب لا تُغلقها (يبتلعها `dsSortableList`).
* **التركيز عند الفتح:** أوّل مقبض — أوّل ما يُفعل في اللوحة. وبعد «استعادة الافتراضي» (يتعطّل بنقرته) إلى أوّل مقبض أيضًا.
* **يبقى فوق «لا نتائج»:** الأعمدة لا تُخفي صفًّا، فلا سبب لإخفاء الزرّ.
* **التصدير لا يتبعه:** الملف بأعمدته المعرَّفة في الصفحة — ما يُخفيه المستخدم من الشاشة لا يُسقطه من ملفّ يُرسل.

### لماذا لوحة لا `<app-menu>`؟

القائمة تُغلق بأوّل نقرة داخلها — وإظهار عمودين نقرتان متتاليتان. والسحب داخل قائمة ليس من عقدها. فهي لوحة عائمة (`FloatingPanel`) بـ `role="dialog"` كلوحة الفلترة، بلا خلفية معتمة.

### الحفظ

في **هذا المتصفح** (`localStorage` بمفتاح `ds-table-columns:<المفتاح>`) حتى يحفظه الخادم للمستخدم — [`REQ-078`](../../BACKEND-REQUIREMENTS.md).

* **يُقرأ بعد أوّل رسم** (`afterNextRender`) لا في المُنشئ: الخادم يرسم الترتيب الافتراضي، وقراءته قبل الـhydration ترسم جدولًا آخر فوق HTML الخادم (NG0500).
* **الحالة الافتراضية لا تُحفظ** — يُمسح المفتاح، فعمود يُضاف إلى التعريف لاحقًا يصل المستخدم.
* **`normalizeColumnsState`** يصحّح المحفوظ على تعريف اليوم: مفتاح لم يعد موجودًا يسقط، وعمود جديد يُلحق آخرًا ظاهرًا، والثابت لا يدخل الحالة.
* تخزين محجوب (نافذة خاصّة) لا يكسر شيئًا: يبقى الترتيب للجلسة.

## 9. الاستجابة

### الجوال

الزرّ في سطر الأفعال تحت البحث والفلتر ([`filtering.md`](../patterns/filtering.md))، واللوحة نفسها لا درج: عمود واحد بعرض 264 يسع الشاشة، و`FloatingPanel` يُبقيها 16px عن حافّتيها.

## 10. RTL

* الزرّ في طرف النهاية (يسارًا في العربية)، واللوحة تمتدّ من حافّة نهايته نحو الجدول (`FloatingPanel` بـ `align: 'end'`).
* المقبض في طرف البداية من كل صفّ، كصفوف الجدول. والأسهم ↑↓ عمودية فلا تنعكس.
* كل المسافات منطقية.

## 11. إمكانية الوصول

| المتطلب | كيف |
|---|---|
| الزرّ | `aria-haspopup="dialog"` و`aria-expanded` |
| اللوحة | `role="dialog"` باسم «أعمدة الجدول» |
| المربّع | `<app-checkbox>` واسمه اسم العمود |
| الثابت | مربّع معطَّل موصوف بـ «ثابت» (`aria-describedby`) — يُقرأ السبب مع الاسم |
| المقبض | زرّ حقيقي «إعادة ترتيب المدرب»، والنقل يُعلن موضعه |
| الحالة | الظهور في المربّع (شكل) لا في اللون وحده |

## 12. النصوص

← نصّ الزرّ «الأعمدة» واسم اللوحة «أعمدة الجدول» قيمتان افتراضيتان في §7، و«ثابت» و«استعادة الافتراضي» في §3، و«تخصيص البطاقات» و«كل البطاقات مخفية» و«إظهار كل البطاقات» في §4. وأسماء الأعمدة اسم الرأس حرفًا بحرف (`label`، §7).

## 13. مثال

```html
<ng-container toolbar-actions>
  <button dsButton variant="secondary" (click)="exportCourses()">…تصدير كملف إكسل</button>
  <app-table-columns [columns]="columnDefs" [state]="columnsState" (stateChange)="onColumnsChange($event)" />
</ng-container>
```

```ts
readonly columnDefs: readonly TableColumn[] = [
  { key: 'name', label: 'الدورة', locked: true },
  { key: 'trainer', label: 'المدرب' },
  { key: 'enrollments', label: 'الاشتراكات' },
  …
];
columnsState = defaultColumnsState(this.columnDefs);
dataColumns = visibleColumnKeys(this.columnsState);   // ما يرسمه الرأس والصفوف بعد الثابت

constructor() {
  // بعد أوّل رسم لا في المُنشئ — انظر «الحفظ».
  afterNextRender(() => {
    const saved = readColumnsState('admin-courses', this.columnDefs);
    if (saved) { this.applyColumns(saved); this.cdr.detectChanges(); }
  });
}

onColumnsChange(state: TableColumnsState) {
  this.applyColumns(state);
  writeColumnsState('admin-courses', this.columnDefs, state);
}
```

والجدول يرسم أعمدته من `dataColumns` — رأسًا وهيكل تحميل وخلايا، بالترتيب نفسه:

```html
@for (column of dataColumns; track column) {
  @switch (column) {
    @case ('trainer') { <th scope="col" class="ds-table__nowrap">المدرب</th> }
    …
  }
}
```

وصفّ «لا نتائج» `[attr.colspan]` بعدد الأعمدة الظاهرة لا رقمًا ثابتًا.

## 14. ممنوع

* ❌ إخفاء العمود الذي يُعرف به الصفّ، أو جعله متحرّكًا.
* ❌ زرّ «تطبيق» — التغيير يسري فورًا.
* ❌ أن يُسقط الإخفاء عمودًا من ملف التصدير.
* ❌ قراءة الحالة المحفوظة قبل أوّل رسم.
* ❌ `colspan` ثابت في صفّ «لا نتائج» تحت جدول بأعمدة متغيّرة.

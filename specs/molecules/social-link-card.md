# بطاقة حساب التواصل — social-link-card

> منصّة واحدة بلون علامتها، اللون فيها هو الحالة — فلا شارة ولا فلتر.

## 1. متى تستخدمه

### ما هي

بطاقة تعرض **منصّة تواصل واحدة** وحالتها: حسابٌ مضاف إلى موقع الأكاديمية أو منصّةٌ لم يُضف لها حساب بعد. وهي بطاقة **خاصّة بشاشتها**، لا مكوّن في `shared/ui` — لأن لا شاشة أخرى في اللوحة تعرض منصّات تواصل. فإن ظهرت شاشة ثانية تحتاجها، تُرفع إلى `shared/ui` عندها لا قبله.

## 2. متى لا تستخدمه

> ⚠️ **غير موثّق بعد:** متى لا تُستعمل البطاقة وما البديل. الأصل يحصرها في شاشتها ([§1](#ما-هي))، ويحجز «تم الربط» لصفحة التطبيقات ([§12](#ما-لا-تعرضه-ولن-تعرضه)).

## 3. التشريح

```
┌─────────────────────────────────┐
│ [شعار]  @acadimiat        [↗]   │  ← رأس بلون العلامة
│         فيسبوك                   │
├─────────────────────────────────┤
│ facebook.com/acadimiat [نسخ]  [تعديل][حذف] │
└─────────────────────────────────┘
```

### بقيّة القطع — كلّها من النظام

| القطعة | المكوّن |
|---|---|
| البطاقة الحاوية والشبكة | `<app-card padding="none">` |
| زرّا التعديل والحذف | `<button dsButton variant="tertiary" size="sm" [iconOnly]="true">` |
| زرّ «إضافة الرابط» | `<button dsButton variant="secondary" size="sm">` |
| النسخ | أيقونة `design-tools/copy` بجوار القيمة في خليّتها (نمط الجداول) |
| الفتح | `arrow/export-arrow-02` في رابط `target="_blank"` |
| التعديل | `content-edit/edit` · الحذف `essential/trash` |
| نافذة الرابط | `<app-modal>` بحقل واحد `kind="code"` بلاصقة `https://` وزرّ مسح |
| تأكيد الحذف | `ConfirmOverlayService` · `kind: 'delete-content'` |
| مفتاح الأيقونات الملوّنة | `<app-toggle>` في صفّ إعداد داخل `<app-card>` بلا عنوان |
| التحميل · الخطأ | `<app-skeleton-group>` · `<app-empty-state variant="error">` |

### الشعارات

من **`fa-brands`** — المصدر المعتمد لشعارات المنصّات حتى تنتهي هجرة الأيقونات ([CLAUDE.md § Icons](../../../CLAUDE.md)). و`fa-x-twitter` غير موجود في الحزمة المرفقة (6.0.0-beta2)؛ يرسمه `src/styles.scss` بقناع واحد بـ`currentColor`، فيرمدّ مع بقيّة الشعارات حين لا يكون الحساب مضافًا.

**ما ليس عندنا:** المنتج لا يملك ملفات شعارات ملوّنة إلا لتيك توك وسناب شات وإكس وثريدز وميتا. فشعارات هذه الشاشة **شعارات المنتج مصبوغة** بألوان أصحابها — لا ملفّ نُزِّل من الإنترنت. وإن طُلبت الشعارات الرسمية بملفاتها (خاصةً تدرّج إنستغرام) فذلك إضافة ثمانية ملفات إلى `src/assets/icons/`، قرارٌ يُعرض ويُعتمد قبل تنفيذه.

## 4. الأنواع والمقاسات

### المقاسات

- الشبكة: 3 أعمدة · عمودان تحت 1200 · عمود واحد تحت 768.
- الشعار 40×40 برادياس 8 على سطح أبيض · رأس البطاقة 76 كحدّ أدنى.
- زرّ الفتح 32×32 · زرّ النسخ 24×24 داخل تذييل ارتفاعه 44 (هدف اللمس).
- الحشوة 20 في البطاقة و16 على الجوال · الفجوة بين البطاقات 16.

## 5. الحالات

### الحالتان

| | مضاف | غير مضاف |
|---|---|---|
| خلفية الرأس | لون العلامة مخفَّفًا (`--social-tint`) | `--ds-color-surface-hover` |
| الشعار | بلون العلامة (`--social-brand`) | `--ds-neutral-400` |
| السطر الأول | `@المعرّف` (مشتقّ من الرابط) | اسم المنصّة |
| السطر الثاني | اسم المنصّة | «لم يُضف بعد» |
| زرّ الفتح ↗ | موجود | غائب |
| التذييل | الرابط + نسخ · تعديل · حذف | «لا يظهر في موقعك» + «إضافة الرابط» |

**اللون هو الحالة.** ولذلك لا شارة `<app-status>` في البطاقة ولا فلتر «المضافة / غير المضافة» فوق الشبكة (قرار المنتج 2026-09-16): الشبكة تُقرأ بلمحة، وشارةٌ في كل بطاقة تكرّر ما قاله اللون.

وفي الكود أيضًا (وُثّق 2026-09-26 من الكود):

| الحالة | الشكل |
|---|---|
| أثناء حفظ منصّة | البطاقة بشفافية `0.6`، و«تعديل» و«حذف» معطَّلان، و«إضافة الرابط» بحالة `loading` |
| تمرير فوق «حذف» | لون `--ds-color-text-danger` — عند المرور وحده |
| تمرير فوق الفتح ↗ | `--ds-color-surface-hover` |
| تمرير فوق النسخ | `--ds-color-surface-sunken` ونصّ `text-primary` |
| تركيز الفتح والنسخ | `--ds-focus-ring` |
| المعرّف | `@` قبله إلا لواتساب (رقم لا اسم)؛ ورابط بشكل غير معتاد يُعرض عنوانه كما هو بلا تخمين (`handleOf` في `social-platforms.ts`) |
| فوق الشبكة | عدّاد لا فلتر في رأس `<app-card>`: «**{{ addedCount }}** من {{ platforms.length }} حسابًا مضافًا» (قرار المستخدم 2026-09-16 في تعليق القالب) |

← التحميل والخطأ: `<app-skeleton-group>` و`<app-empty-state variant="error">` في [بقيّة القطع](#بقيّة-القطع--كلّها-من-النظام).

## 6. التوكنز

### ألوان العلامات — الاستثناء الوحيد

`--social-brand` و`--social-tint` **ليستا من ألوان نظام التصميم**. هما لون العلامة كما يملكه صاحبها، ويدخلان على البطاقة وحدها من جدول `social-platforms.ts`.

**تُستعملان للشعار وخلفيته فقط.** لا لنصّ، ولا لزرّ، ولا لحالة، ولا لحدّ. النصّ فوق الخلفية الملوّنة `--ds-color-text-primary`، والخلفيات مخفَّفة إلى الدرجة التي يمرّ فوقها تباين WCAG AA.

| المنصّة | `brand` | `tint` |
|---|---|---|
| فيسبوك | `#1877F2` | `#EAF2FE` |
| إنستغرام | `#DD2A7B` (والشعار متدرّج) | `#FDEFF6` |
| واتساب | `#1FA855` | `#E9F7EF` |
| تيك توك | `#010101` | `#F0F0F1` |
| يوتيوب | `#FF0000` | `#FFEDED` |
| إكس | `#000000` | `#F0F0F1` |
| سناب شات | `#B8A700` | `#FFFCE0` |
| تيليجرام | `#26A5E4` | `#E9F6FD` |
| لينكدإن | `#0A66C2` | `#E8F1FA` |
| بينتريست | `#E60023` | `#FDECEE` |
| بيهانس | `#1769FF` | `#E9F0FF` |

أصفر سناب شات الرسمي (`#FFFC00`) لا يُرى على أبيض، فالشعار بدرجته الداكنة والخلفية بدرجته الفاتحة.

← توكنز النظام في البطاقة (`--ds-color-surface-hover` · `--ds-neutral-400`) في [الحالتان](#الحالتان).

وفي `settings-media-tab.component.scss` قيم خام غير لونَي العلامة (قيس 2026-09-26): ارتفاع الرأس الأدنى `76px`، والشعار `40px`، وزرّ الفتح `32px`، وزرّ النسخ `24px`، وتدرّج شعار إنستغرام `#f58529 → #dd2a7b → #8134af`، وشفافية الحفظ `0.6`. والباقي توكنز: البطاقة `surface-default` بحدّ `border-subtle` واستدارة `--ds-radius-lg` (12)، والرأس حشوة 16 وفجوة 12، والتذييل حشوة 12 / 16 وفجوة 8 وفاصل `divider`، والمعرّف 14/600، واسم المنصّة والرابط 12 `text-muted` (الرابط بخط `--ds-font-family-mono`).

## 8. السلوك ولوحة المفاتيح

### الحفظ

**فعلٌ لكل منصّة، لا زرّ «حفظ» واحد في آخر الصفحة.** كل منصّة تُضاف أو تُعدَّل من نافذتها وتُحفظ وحدها، وتُحذف بتأكيد.

الخادم يستقبل نموذج المنصّات كلّه في طلب واحد (`POST websites/socialmedia`)، فحفظ منصّة واحدة يرسل النموذج كلّه بحقلٍ مبدَّل. وإن رفض الخادم تعود القيمة السابقة فورًا — لا تبقى بطاقة تدّعي ما لم يُحفظ.

## 10. RTL

ما يفعله الكود:

* **المعرّف `@…` LTR** (`direction: ltr` على نصّه)، وعمود المعرّف واسم المنصّة يحاذي أبناءه على بداية السطر، وكلٌّ بعرض محتواه — فيبدأ المعرّف اللاتيني والاسم العربي من الحرف نفسه يمينًا في العربية.
* **اسم المنصّة في مكان المعرّف** (غير المضاف) يعود إلى اتجاه الصفحة (`direction: inherit`).
* **الرابط LTR** بسمة `dir="ltr"` و`direction: ltr` و`text-align: start`، ويُقصّ بـ«…».
* **سهم الفتح `arrow/export-arrow-02` لا ينعكس** — بلا `directional`.
* الصفّ والتذييل بخصائص منطقية وflex، فالشعار في البداية وزرّ الفتح والأفعال في النهاية في الاتجاهين.

(وُثّق 2026-09-26 من الكود)

## 11. إمكانية الوصول

> اللون **زينة لا معنًى وحيدًا**: من لا يميّز الألوان يقرأ «لم يُضف بعد» وزرّ «إضافة الرابط» — والمعلومة كاملة عنده (WCAG 1.4.1).

← هدف اللمس 44 في التذييل — [المقاسات](#المقاسات).

## 12. النصوص

### ما لا تعرضه ولن تعرضه

**أرقام المتابعين.** تحتاج ربط حساب حقيقي بالمنصّة وقراءة بياناتها من الخادم. الشاشة تخزّن رابطًا مكتوبًا بيد صاحب الأكاديمية، فلا رقم بلا مصدر.

**كلمة «مرتبط».** الحساب هنا **مضاف** لا **مرتبط**: لا تسجيل دخول ولا تحقّق. و«تم الربط» محجوزة لصفحة التطبيقات حيث تعني ما تقول (قرار المنتج 2026-09-12).

## 13. مثال

البطاقة قالب داخل `settings-media-tab.component.html` لا مكوّن يُستدعى — هذا القالب مختصرًا:

```html
<app-card heading="حسابات التواصل" description="الحسابات التي تظهر أيقوناتها في موقعك."
  padding="none" [hasHeaderActions]="true">
  <span card-actions class="social-page__count"><b>{{ addedCount }}</b> من {{ platforms.length }} حسابًا مضافًا</span>

  <div class="social-grid">
    @for (p of platforms; track p.key) {
      <article class="social-card" [class.social-card--off]="!isAdded(p)" [class.social-card--saving]="isSaving(p)"
        [style.--social-brand]="p.brand" [style.--social-tint]="p.tint">
        <div class="social-card__top">
          <span class="social-card__logo" aria-hidden="true"><i class="fa-brands {{ p.icon }}"></i></span>
          <span class="social-card__id">…المعرّف واسم المنصّة…</span>
          @if (isAdded(p)) {
            <a class="social-card__open" [href]="publicUrlOf(p)" target="_blank" rel="noopener noreferrer"
              [attr.aria-label]="'فتح حساب ' + p.name + ' في نافذة جديدة'">
              <ds-icon name="arrow/export-arrow-02" size="sm" />
            </a>
          }
        </div>
        <div class="social-card__foot">
          @if (isAdded(p)) {
            <span class="social-card__link">
              <span class="social-card__url" dir="ltr">{{ valueOf(p) }}</span>
              <button type="button" class="social-card__copy" [attr.aria-label]="'نسخ رابط ' + p.name" (click)="copy(p)">
                <ds-icon name="design-tools/copy" size="sm" />
              </button>
            </span>
            <span class="social-card__actions">…«تعديل» و«حذف» dsButton tertiary sm iconOnly…</span>
          } @else {
            <span class="social-card__empty">لا يظهر في موقعك</span>
            <button dsButton type="button" variant="secondary" size="sm" [loading]="isSaving(p)"
              (click)="openLinkDialog(p)">إضافة الرابط</button>
          }
        </div>
      </article>
    }
  </div>
</app-card>
```

(وُثّق 2026-09-26 من الكود)

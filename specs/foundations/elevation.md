# الظلال — الأسس

> يحكم مستويات الارتفاع (الظل) التي تفصل الطبقات بعضها عن بعض.

## 1. المبدأ

خمسة مستويات، **خافتة عمدًا**. لوحة التحكم أداة عمل لا صفحة تسويق؛ الظل هنا يفصل الطبقات لا يزيّنها (UI-16).

## 2. القيم

> القيم في هذا الجدول هي الوحيدة المسموحة — [القاعدة](../../DESIGN.md#القيم-المسموحة) · [المرجع السريع](../../migration/PLAYBOOK.md).

| توكن | القيمة (من `tokens.css`) | متى |
|---|---|---|
| `--ds-elevation-0` | `none` | مسطح على السطح |
| `--ds-elevation-1` | `0 1px 2px rgba(16, 16, 20, 0.06), 0 1px 3px rgba(16, 16, 20, 0.04)` | بطاقة مرفوعة |
| `--ds-elevation-2` | `0 2px 4px rgba(16, 16, 20, 0.06), 0 4px 8px rgba(16, 16, 20, 0.05)` | قائمة منسدلة، منبثق |
| `--ds-elevation-3` | `0 4px 8px rgba(16, 16, 20, 0.06), 0 12px 20px rgba(16, 16, 20, 0.08)` | حوار، Toast |
| `--ds-elevation-4` | `0 8px 16px rgba(16, 16, 20, 0.08), 0 24px 40px rgba(16, 16, 20, 0.10)` | درج جانبي |

## 3. الاستعمال

> لا ينطبق — الاستعمال عمود «متى» في جدول §2، وشجرته في §5.

## 4. قواعد إلزامية

> ⚠️ **غير موثّق بعد:** قاعدة إلزامية مكتوبة للظلال (مثل منع ظلّ بقيمة حرة خارج `--ds-elevation-*`) — الأصل يكتفي بالجدول والمبدأ. وما يخصّ الوضع الداكن («الظل الأسود لا يُرى على خلفية داكنة؛ الفصل يكون بالحدود») بند مفتوح في [`dark-mode.md`](./dark-mode.md#4-قواعد-إلزامية).

## 5. شجرة القرار

من عمود «متى» في جدول §2:

```
أين العنصر من السطح؟
├── مسطح على السطح          → --ds-elevation-0
├── بطاقة مرفوعة            → --ds-elevation-1
├── قائمة منسدلة، منبثق     → --ds-elevation-2
├── حوار، Toast             → --ds-elevation-3
└── درج جانبي               → --ds-elevation-4
```

## 6. افعل / لا تفعل

> ⚠️ **غير موثّق بعد:** أزواج ✓ / ✗ لهذا الأساس — لا يكتبها الأصل.
